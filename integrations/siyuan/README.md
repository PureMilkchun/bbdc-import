# 不背单词导入 · 思源桌面插件

在思源内置 Agent 里批量把英文词加入「不背单词」，无需 Python、终端或额外服务。需要思源桌面版 3.8.6 或更新版本，并在本机打开工作空间。

1. 下载 `bbdc-import-siyuan.zip`，在思源「设置 → 集市」里使用本地 ZIP 安装，再启用「不背单词导入」插件。这个包不是通用 Skill 安装包。
2. 点击顶部工具栏的「不背单词 · 登录」，在独立窗口登录自己的账号。登录后关掉窗口，再回到 Agent；网站会话过期时重新登录即可。
3. 在思源 Agent 中说：「用不背单词生词本工具，把 resilient、vivid 加入我的生词本。」如果 Agent 看不到工具，在「设置 → AI → Agent 能力」启用「不背单词生词本」，再开一个新对话。

推送前会显示实际提交的词，确认才写入。一次最多 20 个词，长词表分批；也可要求「只核对，不上传」。如果返回「结果待核对」，先核对该词是否已在生词本，再决定是否重试。

登录保存在插件独立的浏览器会话里，不读取日常浏览器的 Cookie。插件不需要读取或修改思源笔记；Agent 传入选定的英文词，插件分别向不背单词和词典查询。网页版和移动端可改用 WordRadar CSV。
